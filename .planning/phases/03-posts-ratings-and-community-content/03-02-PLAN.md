<mutation_authorization_matrix>
| Mutation or read | Guest | Authenticated unverified | Verified non-member | Verified member | Admin |
|---|---|---|---|---|---|
| Read public university reviews/aggregates/feed activity | allow | allow | allow | allow | allow |
| Submit review/rating | deny 401 | deny 403 | allow when verified | allow when verified | follow verification rule; admin role alone does not make an unverified user eligible |
| Update own review/rating | deny 401 | deny 403 unless this implementation adds no update path | not applicable unless implementation detail update path is chosen | not applicable unless implementation detail update path is chosen | no moderation/bypass behavior; no update via admin ownership bypass |
| Duplicate second review/rating in same university | deny 401 if guest | deny 403 if unverified | deny conflict | deny conflict | deny conflict; database uniqueness remains authoritative |
| Read/mutate cross-university review by guessed ID/slug | deny protected mutation 401; public read only under requested public slug | deny protected mutation 403; no cross-slug data | deny 404/403 as scoped | deny 404/403 as scoped | no cross-university bypass; scope remains enforced |

This matrix preserves public reads and uses only the existing SRS authorization facts: verified users submit reviews/ratings; unverified and guest users cannot submit. It intentionally does not require CommunityMembership for review submission because no SRS rule adds membership to that mutation. Admin moderation and later management features are outside this plan.
</mutation_authorization_matrix>

## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser to review API | Review text, category values, university slugs, review IDs, and bearer tokens are untrusted. |
| Express service to PostgreSQL | The service maps current authenticated users and route-scoped universities to constrained writes and aggregates. |
| Aggregate response to browser | Derived scores and counts are public output; request clients must not control them. |
